# Support

HillDesk is a free, volunteer-maintained open-source project.

**What's offered**

- The code, the documentation in `docs/`, and fixes released here
- Security fixes on the timeline in [SECURITY.md](SECURITY.md)
- Answers in GitHub Discussions when time allows

**What isn't offered**

- Deployment, configuration or setup help for individual offices
- Hosting, monitoring or operating HillDesk for anyone
- A service-level agreement of any kind

**Where to ask**

- Questions and ideas: GitHub Discussions
- Bugs: GitHub Issues, using the templates. Never paste real email or
  constituent data.
- Vulnerabilities: privately, as described in [SECURITY.md](SECURITY.md)

**House offices:** your deployment and its approval go through House
Information Resources and your office's IT, not this project.
